## What is it for?

Moving a large file, delivery folder, or internal document to another computer nearby often involves a messenger, cloud drive, or USB stick. Intranet Flash Transfer provides a shorter path:

1. Select a real file or directory in the desktop app.
2. Configure a passcode, expiration time, access mode, and optional IP allowlist.
3. Send the encrypted link or QR code to a visitor.
4. The visitor authenticates in a browser, then previews or downloads in read-only mode.

Files are served directly by your computer and do not need to be uploaded to a third-party service first.

## Highlights

| Capability | Description |
| --- | --- |
| Direct LAN delivery | Detects real IPv4 interfaces and hosts files locally without a cloud relay. |
| QR codes and encrypted links | Each share gets a dedicated access token, QR code, and links for every usable network interface. |
| Passcodes and expiration | Passcodes are stored as salted `scrypt` hashes. Shares can expire after 1 hour, 4 hours, 24 hours, 7 days, or never. |
| Access policies | Supports exact IPs, CIDR ranges, wildcard allowlists, exclusive access, and one-to-many downloads. |
| Explicit mobile switch | Phones and tablets are blocked by default and must be enabled for each share. |
| Resume and verification | Single-file downloads support HTTP Range resume and verify SHA-256 plus file size on completion. |
| Batch ZIP downloads | Visitors can select multiple files or folders and receive a ZIP generated by the desktop host. |
| Read-only visitor UI | Visitors can authenticate, preview, and download, but cannot upload, modify, or delete host files. |
| Lightweight desktop app | Built with Tauri 2, Rust, and the system WebView; the macOS installer is roughly 5 MB. |

## How it works

### 1. Create a share

Choose the network interface and port, then select a local file or directory. Configure the share name, passcode, expiration, and access policy.

### 2. Share the entry point

The control center generates a real LAN URL and QR code. Hosts with multiple interfaces can copy every available address at once.

### 3. Download in a browser

The visitor opens the link from the same LAN or a trusted VPN and enters the passcode. Single files support resume, while multiple selected items can be downloaded as a ZIP.

### 4. Verify the result

The control center reports leases, transfers, and mobile access. The visitor UI shows live speed, received bytes, and the final SHA-256 verification receipt.

## Security model

- Share passcodes are stored as salted `scrypt` hashes, never in plaintext.
- Access-link tokens are generated with a local key and AES-256-GCM and do not contain physical file paths.
- Every file request requires a Bearer Token and remains subject to expiration, client IP, and access-mode policies.
- Authentication attempts are rate-limited to reduce passcode guessing on the local network.
- Path resolution is constrained to the selected share root.
- Mobile access is disabled by default, and public APIs do not reveal host filesystem paths.

> **Important:** The current transfer channel uses LAN HTTP, not end-to-end TLS. Use it only on a trusted LAN, isolated network, or trusted VPN. Do not expose the service port directly to the public internet.

## Technology

- **Desktop runtime:** Tauri 2
- **Local service:** Rust, Axum, Tokio
- **UI:** React 19, TypeScript, Tailwind CSS 4
- **Security and verification:** AES-256-GCM, scrypt, SHA-256, MD5
- **Packaging:** macOS APFS DMG, Windows NSIS, GitHub Actions

## Development

### Requirements

- Node.js 24+
- Rust stable
- The [Tauri 2 system prerequisites](https://v2.tauri.app/start/prerequisites/) for macOS or Windows

```bash
git clone https://github.com/huoxuhaohaode/intranet-flash-transfer.git
cd intranet-flash-transfer
npm install
npm run tauri:dev
```

## Building

```bash
# Type checking
npm run lint

# macOS DMG — build on macOS
npm run tauri:build:mac

# Windows NSIS EXE — build on Windows
npm run tauri:build:win
```

Pushing a version tag triggers GitHub Actions to build both platforms and publish a Release.

## Versioning

Before each iteration, run:

```bash
npm run version:next
```

Versions use decimal carry: `0.2.1`, `0.2.2` … `0.2.9`, `0.3.0`. The script updates npm, Cargo, and Tauri together, and the packaging script refuses to overwrite an existing release for the same version.
